## 🚀 About This Project

This project is a hands-on exercise to master key concepts in frontend development. The main feature is a dynamic FAQ component that demonstrates proficiency in React, state management, and building a polished user experience.

## ✨ Features
The FAQ component includes:
- **Interactive Accordion:** Users can click to expand and collapse answers. Only one answer can be open at a time.
- **Live Search:** Instantly filter questions and answers by typing in the search bar.
- **Category Filtering:** Organize questions by category and allow users to filter them with a single click.
- **Smooth Animations:** Built with `Framer Motion` for fluid opening/closing animations.
- **Responsive Design:** A clean, modern UI that looks great on all screen sizes, built with `Tailwind CSS`.
- **Iconography:** Clear and consistent icons from `Lucide React` to improve usability.
 
## 🛠️ Tech Stack
- **React** - A JavaScript library for building user interfaces.
- **Vite** - A next-generation frontend build tool.
- **Tailwind CSS** - A utility-first CSS framework for rapid UI development.
- **Framer Motion** - A production-ready motion library for React.
- **Lucide React** - A beautiful and consistent icon toolkit.
- **ESLint** - For maintaining code quality.
 
## ⚙️ Getting Started
 
Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.
 
### Prerequisites
 
Make sure you have Node.js (v18.x or higher) and `npm` installed.
 
### Installation
 
1.  **Clone the repository:**
    ```bash
    git clone <your-repository-url>
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd my-frist-react-app
    ```
3.  **Install the dependencies:**
    ```bash
    npm install
    ```
 
### Running the Development Server
 
To start the development server, run:
 
```bash
npm run dev
```
 
This will start the Vite development server. Open your browser and go to `http://localhost:5173` (or the address shown in your terminal) to see the application.
